# Sinners Lifestyle Platform

## Bienvenido

Este repositorio contiene el desarrollo de la plataforma oficial de Sinners.

## Objetivo

Desarrollar un sistema web profesional para:

- Administración de usuarios
- Eventos
- Reservaciones
- Venta de productos
- Promociones
- Blog
- Información del Lifestyle
- Salud Sexual
- Panel Administrativo
- Reportes

## Estado del proyecto

🚧 En fase de análisis y diseño.

- React
- Next.js
- Spring Boot
- PostgreSQL
- GitHub
